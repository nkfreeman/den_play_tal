# Den Play Tal

Interactive Jupyter notebook project with Binder integration for data analysis.

## Overview

This repository contains an interactive analysis notebook that can be run directly in the browser via Binder.

[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/nkfreeman/den_play_tal/master)

## Requirements

See `requirements.txt`:
- ipywidgets
- matplotlib
- numpy
- pandas
- seaborn
- scikit-learn
- xlrd
- openpyxl

## Usage

**Option 1: Run in Binder**
Click the Binder badge above to launch the notebook in your browser.

**Option 2: Run locally**
```bash
pip install -r requirements.txt
jupyter notebook Final.ipynb
```

## Files

- `Final.ipynb` - Main analysis notebook
- `requirements.txt` - Python dependencies
